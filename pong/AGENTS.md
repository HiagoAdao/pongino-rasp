# Instruções do pacote `pong`

- Siga primeiro o `AGENTS.md` da raiz e todos os `.ai-instructions`.
- Preserve a separação entre domínio, contratos, infraestrutura, API e CLI.
- Use Python 3.12+, type hints completos e `uv run` para validações.
- Não introduza dependência de hardware no pacote inteiro; ela deve ficar no
  adaptador específico.
- Não altere arquivos diretamente pelo agente de mentoria. Oriente o aluno e
  mostre somente trechos curtos quando ele pedir.
- Toda mudança deve ter teste correspondente e uma pergunta de verificação ao
  final da etapa.
